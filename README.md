# 🚀 Dev Metrics

> A GitHub Analytics Dashboard that helps developers track productivity, coding activity, repository health, language usage, and contribution insights through beautiful visualizations.

![Next.js](https://img.shields.io/badge/Next.js-16-black?logo=next.js)

## ✨ Features

### 📊 Developer Dashboard

* GitHub contribution analytics
* Commit activity tracking
* Productivity score calculation
* Current streak & longest streak
* Most active day and coding hours

### 🔥 Commit Insights

* Commit activity visualization
* Push frequency analysis
* Coding consistency tracking
* Development streak monitoring

### 📁 Repository Analytics

* Top repositories ranking
* Repository contribution metrics
* Star statistics
* Repository health overview

### 💻 Language Analytics

* Most used programming languages
* Language distribution visualization
* Technology stack insights

### 🧠 Smart Insights

* AI-inspired productivity recommendations
* Development pattern analysis
* Coding behavior insights

### 🎴 Shareable Dev Card

* Downloadable developer profile card
* GitHub-style statistics showcase
* Social sharing support

## ⚙️ Environment Variables

### Backend (.env)

```env
PORT=5000

MONGODB_URI=your_mongodb_uri

JWT_SECRET=your_jwt_secret

GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret

FRONTEND_URL=http://localhost:3000
```

### Frontend (.env.local)

```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/dev-metrics.git

cd dev-metrics
```

### Backend Setup

```bash
cd backend

npm install

npm run dev
```

### Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
